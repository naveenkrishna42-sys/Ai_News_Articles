Microsoft patches 400+ flaws, including zero-day under active attack

📅 2026-08-12 📂 Technology Original source ↗
Key points
  • Microsoft released patches for more than 400 vulnerabilities in its August 2026 Patch Tuesday update.
  • A zero-day in a Windows driver (CVE-2026-68820) is under active attack, prompting urgent patching.
  • Updates are available for Windows 11 (KB5121003, KB5120240, KB5121000) and other affected products.

Largest Patch Tuesday in recent memory

Microsoft has released its August 2026 Patch Tuesday updates, addressing more than 400 vulnerabilities across its product ecosystem. The sheer volume marks one of the largest monthly security fixes in the company's history, covering Windows, Office, Edge, and several developer tools.

Among the patches are fixes for 398 flaws detailed by third-party researchers, alongside additional advisories. The updates include critical remote code execution bugs, privilege escalation flaws, and information disclosure issues. Security teams are now racing to triage and deploy the patches, prioritising those marked as actively exploited.

Zero-day under attack: CVE-2026-68820

The most urgent item is CVE-2026-68820, a Windows driver vulnerability that is already being exploited in the wild. Microsoft has confirmed that the flaw is under active attack, though it has not yet disclosed the full scope of the campaigns or the threat actors involved.

The vulnerability allows an attacker to gain elevated privileges on a target system, a common stepping stone for deeper compromise. Check Point Research, which flagged the issue in its analysis, noted that driver-related zero-days are particularly dangerous because they can bypass security products and operate at the kernel level.

Microsoft has classified the flaw as 'important' severity but has urged users to apply the update immediately due to active exploitation. Organisations that cannot patch right away are advised to monitor for indicators of compromise and restrict driver installation where possible.

Windows 11 updates and what they include

The Patch Tuesday release includes cumulative updates for Windows 11: KB5121003, KB5120240, and KB5121000. These updates deliver the security fixes and also include non-security improvements, such as stability enhancements and performance tweaks.

For Windows 10 users, Microsoft has provided similar cumulative updates, though the company has been gradually winding down support for older versions. Enterprises using Windows Server variants will also need to apply corresponding patches to protect infrastructure.

Adobe, which often aligns its Patch Tuesday with Microsoft's, has also released its own set of security updates. The Qualys review of the August 2026 Patch Tuesday highlights several critical vulnerabilities in Adobe products that require immediate attention, particularly in Reader and Acrobat.

What security teams should do now

Experts recommend prioritising the zero-day CVE-2026-68820 first, followed by any remote code execution flaws in internet-facing services. Patching should be tested in staging environments before full deployment, but delays carry risk given the active exploitation.

Organisations should also review their endpoint detection and response (EDR) logs for signs of unusual driver loading or privilege escalation attempts. The Windows driver flaw may leave traces that can help identify earlier intrusions.

For home users, enabling automatic updates on Windows 11 is the simplest way to stay protected. The cumulative updates will download and install automatically, though a reboot may be required to complete the process.

Looking ahead

Microsoft is expected to release additional guidance on CVE-2026-68820 in the coming days, including more details on the attack vectors and potential mitigations. Security researchers will likely reverse-engineer the patch to identify the root cause, which could lead to further discoveries.

With the volume of patches this month, experts caution that attackers may exploit the chaos to target laggards. The next few weeks will be critical for organisations to close the gap before more sophisticated attacks emerge.
