Pavel Durov Warns: Outdated iPhones Face Critical Web-Based Hacking Risks

✍️ By TIVRA News Editorial Desk 📅 2026-11-28 📂 Breaking News Original source ↗
Key points
  • Running outdated iOS versions exposes users to zero-day exploits via compromised websites.
  • Telegram CEO Pavel Durov issued a direct warning urging immediate software updates.
  • Users should verify their iOS version and enable automatic updates to mitigate risk.

Urgent Security Alert from Telegram Leadership

Telegram CEO Pavel Durov has issued a critical security advisory to iPhone users, emphasizing the immediate need to update operating systems. The warning highlights that older versions of iOS are vulnerable to sophisticated hacking attempts executed through malicious websites. Durov’s advisory underscores a growing trend where cybercriminals leverage browser-based exploits to bypass traditional security measures on unpatched devices.

This alert is not merely precautionary; it reflects recent intelligence regarding active exploitation campaigns. Users who have neglected software updates for several months face a significantly higher risk of data compromise. The CEO’s direct communication serves as a powerful endorsement of the importance of routine system maintenance for mobile security.

How Web-Based Exploits Target Older iOS Versions

The primary vector for these attacks involves compromised or malicious websites that deliver malware directly to the device. When an iPhone runs an outdated iOS version, it lacks the security patches designed to block specific zero-day vulnerabilities. These exploits can trigger without user interaction, such as clicking a link, or with minimal interaction, such as visiting a specific page.

Once the exploit is triggered, attackers may gain unauthorized access to device data, including messages, contacts, and cached credentials. This method is particularly dangerous because it does not require physical access to the phone or the installation of third-party apps from the App Store. The attack relies entirely on the vulnerability in the operating system’s web rendering engine or underlying kernel.

Technical Implications for Users

From a technical standpoint, this is a classic example of a drive-by download attack. It exploits known or recently discovered flaws in the iOS codebase. Update cycles from Apple are designed to close these gaps, but users who delay updates leave their devices exposed. The risk is compounded for users who frequently browse the web on their mobile devices, increasing the surface area for potential attacks.

Immediate Action Steps for iPhone Owners

All iPhone users should verify their current iOS version immediately. Navigate to Settings, then General, and select About to check the software version. If the version is not the latest available, users should initiate the update process. Downloading large updates over Wi-Fi is recommended to avoid data charges and ensure a stable connection.

Additionally, enabling automatic software updates provides a layer of passive security. This feature ensures that the device receives critical security patches as soon as they are released by Apple. Users should also review their app privacy settings and consider using a reputable security suite for additional monitoring, although the primary defense remains the operating system update.

Verifying Device Security Post-Update

After updating to the latest iOS version, users should monitor their device for any unusual behavior, such as rapid battery drain or unexpected background activity. While the update mitigates the specific vulnerability highlighted in the warning, ongoing vigilance is crucial. Installing only apps from the official App Store and avoiding suspicious links remains a foundational practice for mobile security.

The Broader Context of Mobile Security in 2026

In the current digital landscape, mobile devices hold an unprecedented amount of personal and professional data. The shift towards zero-trust security models requires users to be more proactive in managing their device health. The warning from Durov aligns with broader cybersecurity trends where software supply chain and operating system vulnerabilities are primary targets.

Organizations and individuals alike must adopt a security-first mindset. Regular updates, strong authentication methods, and cautious browsing habits are no longer optional but essential components of digital hygiene. This incident serves as a reminder that security is a continuous process, not a one-time setup.

  • Update Immediately: Check for iOS updates and install the latest version to patch known vulnerabilities.
  • Enable Auto-Updates: Turn on automatic updates to ensure future security patches are applied without manual intervention.
  • Browse Cautiously: Avoid clicking on suspicious links or visiting untrusted websites, especially on mobile devices.
  • Verify App Sources: Ensure all applications are downloaded from the official App Store to avoid malicious code.
