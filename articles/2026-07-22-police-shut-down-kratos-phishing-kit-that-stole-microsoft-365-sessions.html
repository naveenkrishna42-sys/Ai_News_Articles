Police Shut Down Kratos Phishing Kit That Stole Microsoft 365 Sessions, Bypassed MFA

📅 2026-07-22 📂 Technology Original source ↗
Key points
  • Police dismantled the Kratos phishing kit targeting Microsoft 365 users.
  • The kit could bypass multi-factor authentication by stealing session tokens.
  • The operation involved coordinated action by law enforcement agencies.

Law enforcement agencies have dismantled the Kratos phishing kit, a sophisticated tool designed to steal Microsoft 365 session tokens and bypass multi-factor authentication (MFA). The kit, which allowed hackers to clone Microsoft login portals, captured credentials and session tokens in real time.

How Kratos Worked

The Kratos phishing kit operated by mimicking legitimate Microsoft login pages. When a victim entered their credentials, the kit intercepted them and used the captured session token to gain persistent access to the account. This technique rendered MFA useless because the attacker used the session token directly, bypassing the need for a second authentication factor.

Security researchers noted that the kit was marketed on underground forums as a turnkey solution for less technically skilled hackers. It lowered the barrier to entry for account takeovers, making it accessible to a wider range of cybercriminals.

Scale of the Threat

The takedown follows multiple warnings about similar tools. The FBI had earlier warned about the Kali365 phishing platform, also targeting Microsoft 365 users. Reports indicated that Floridians alone had lost $12 million to such attacks.

Authorities have not yet disclosed the number of victims or the financial losses directly linked to the Kratos kit. However, the operation underscores the growing sophistication of phishing campaigns that target enterprise and personal accounts alike.

Phishing Kits in the Wild

Kratos was not an isolated case. Other kits, such as Forg365, were specifically designed to lower the barrier for Microsoft 365 account takeovers. Hackers also abused Microsoft's Device Code Flow to bypass MFA, using a feature intended for devices without browsers to hijack accounts.

The coordinated takedown involved multiple law enforcement agencies and cybersecurity firms. Details of the operation remain limited, but officials confirmed that servers and domains used by the kit have been seized.

Users are advised to use hardware-based security keys and to remain cautious of unsolicited login prompts. Monitoring session activity for unusual logins from unfamiliar locations can also help detect compromise.

The dismantling of Kratos is a significant blow to the cybercrime ecosystem, but the threat landscape continues to evolve. Security experts expect copycat kits to emerge, and authorities are urging organisations to adopt phishing-resistant authentication methods.
