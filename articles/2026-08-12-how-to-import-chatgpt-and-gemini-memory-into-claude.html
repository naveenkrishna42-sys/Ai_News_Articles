How to Import ChatGPT and Gemini Memory into Claude

📅 2026-08-12 📂 AI Tips & Tools Original source ↗
Key points
  • Anthropic launched a memory import feature for Claude
  • It transfers chat history from ChatGPT and Gemini
  • Step-by-step guide to import and manage memory

Why You'd Want to Move Memory to Claude

If you've been using ChatGPT or Gemini for months, your chat history holds your preferences, project details, and writing style. Switching to Claude meant losing that context. Anthropic's new feature changes that.

It lets you import your memory from ChatGPT and Gemini directly into Claude. That means your new assistant starts with a head full of your past conversations. No more repeating yourself.

What Exactly Gets Imported

The import pulls your saved memory entries — the things you've explicitly asked the assistant to remember. It doesn't bring over every casual chat or temporary conversation. That's a good thing, because it keeps the transfer clean.

You'll need an active Claude account, and you must be logged in. The feature works on both free and paid tiers, though paid users get higher limits on how much memory they can import.

Step-by-Step Guide to Import Memory

Here's how to move your memory from ChatGPT or Gemini to Claude. Follow these steps in order.

  • Step 1: Open Claude in your browser or the desktop app. Go to Settings (the gear icon in the bottom left).
  • Step 2: Click on 'Memory' in the left sidebar. You'll see an option that says 'Import memory from another assistant.'
  • Step 3: Choose your source — ChatGPT or Gemini. A new window will open asking you to log into that account.
  • Step 4: Authorize the connection. Claude will ask for permission to read your saved memory. This is a read-only access, so nothing gets changed on the source account.
  • Step 5: Review the preview. Claude shows you a list of memory entries it found. You can uncheck any you don't want to bring over.
  • Step 6: Hit 'Import'. Claude will process the memory and show you a confirmation. It usually takes under a minute.
  • Step 7: Check your Claude memory section. You'll see the imported items listed alongside any you already had. You can edit or delete them anytime.

What to Do After Importing

Once the import is done, test it. Ask Claude a question that depends on your imported memory, like 'What's my preferred email sign-off?' or 'Remind me of my project deadlines.' If the answers match what you'd expect, the transfer worked.

You should also clean up. Imported memory may contain outdated info or duplicates. Go through the list and remove anything stale. This keeps Claude's responses accurate.

One caveat: if you use Claude's Projects or Team features, the imported memory lands in your personal profile, not in any shared workspace. You'll need to manually add relevant bits to each project if you want them there.

When This Feature Helps and When It Doesn't

This import tool is perfect when you're making a permanent switch to Claude and want your context to carry over. It saves hours of re-teaching.

But it's not useful if you only use ChatGPT or Gemini occasionally, or if you don't have much saved memory in the first place. In those cases, just start fresh — it's faster.

Anthropic hasn't confirmed whether the import works in reverse (from Claude to others), so don't rely on that. For now, this is a one-way street.
