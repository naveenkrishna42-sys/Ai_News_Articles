Microsoft Steps In After LG Monitors Serve McAfee Ads Via Windows 11

📅 2026-07-24 📂 Technology Original source ↗
Key points
  • LG monitors were using a Windows 11 feature to display McAfee ads as pop-ups.
  • Microsoft intervened, asking LG to stop the practice, which was seen as bloatware.
  • LG has agreed to remove the unwanted pop-up ads following Microsoft's pressure.

Unwanted Pop-Ups on LG Monitors

LG has agreed to remove unwanted pop-up advertisements that were appearing on Windows 11 systems through its monitors. The ads, which promoted McAfee antivirus software, were reportedly triggered by a Windows 11 feature.

The issue came to light after users noticed persistent pop-ups for McAfee on their LG monitors. The ads were not part of the Windows operating system itself but were being delivered via LG's monitor software, which uses a Microsoft feature to display notifications.

Microsoft's Intervention

Microsoft stepped in after the practice became public. The company reportedly asked LG to stop using the Windows 11 notification system for advertising. Sources indicate that Microsoft considered the pop-ups a form of bloatware that degraded the user experience.

LG has now confirmed it will remove the ads. The company said it will stop the pop-ups in an upcoming software update. The move follows multiple reports from tech outlets including The Verge, Ars Technica, and PCMag, which detailed how LG monitors were serving McAfee ads through a Windows 11 feature.

Industry Reaction

The incident has drawn criticism from users and tech analysts. Many saw the ads as an unwanted intrusion into the Windows 11 desktop environment. The practice highlighted how third-party hardware makers can exploit operating system features for advertising.

McAfee's involvement also raised questions. The security software company has a history of pre-installed software on new PCs, often criticised as bloatware. In this case, the ads appeared even on systems without McAfee installed, suggesting LG had a direct deal with the company.

Microsoft's response signals a stricter stance on such practices. The company has previously taken steps to reduce bloatware on Windows 11, including limiting pre-installed apps. By pressuring LG, Microsoft is reinforcing its policy that the Windows notification system should not be used for third-party ads.

What This Means for Users

For users who encountered the pop-ups, LG's update should resolve the issue. The company has not specified a timeline for the fix, but it is expected to roll out via the LG Control Center software. Users can also manually disable notifications from the LG software in the meantime.

The incident serves as a reminder that hardware makers can sometimes push ads through their software. Microsoft's intervention shows it is willing to act when such practices cross a line. The company has not commented on whether it will take similar action against other manufacturers.

Moving forward, LG will need to ensure its monitor software does not use Windows features for advertising. Microsoft is likely to monitor the situation closely, as the company works to maintain a clean user experience on its flagship operating system.
