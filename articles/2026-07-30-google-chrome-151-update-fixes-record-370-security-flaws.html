Google Chrome 151 Update Fixes Record 370 Security Flaws

📅 2026-07-30 📂 Technology Original source ↗
Key points
  • Chrome 151.0.7922.71/.72 patches 370 vulnerabilities, a record for a single update
  • Seven of the flaws are rated critical, the highest severity level
  • The update also includes a new Web API for streaming text

Record-Breaking Patch

Google has released Chrome 151.0.7922.71/.72, addressing a staggering 370 security vulnerabilities. This is the largest single security update in the browser's history. The previous record was 107 fixes in Chrome 116.

The update covers both the Windows and Mac versions of the browser. Users are strongly advised to update immediately.

Critical Flaws Patched

Among the 370 fixes, seven vulnerabilities are rated critical. Google has not yet disclosed technical details for most of these critical flaws. The company typically holds back such information until a majority of users have installed the update.

Critical vulnerabilities in Chrome can allow an attacker to take full control of a user's system. This makes them a prime target for cybercriminals and state-sponsored hacking groups.

New Streaming API

The update is not just about security. Chrome 151 also introduces a new Web API for streaming text. This could simplify how web applications handle real-time data, such as live captions or chat feeds.

Developers have been asking for a standardised way to stream text without relying on third-party libraries. Google says the new API will reduce complexity and improve performance.

What Users Should Do

Chrome will typically update itself in the background. Users can check their version by navigating to chrome://settings/help. If the version is not 151.0.7922.71 or later, a manual restart of the browser may be needed.

Enterprise administrators should prioritise this update across their fleets. Given the number of critical patches, delaying the update could expose organisations to significant risk.

Google has not confirmed how many of the 370 vulnerabilities were discovered internally versus reported by external researchers. The company's bug bounty program has been a major driver of Chrome security improvements over the years.

This update is expected to be the last major security release before Google shifts its focus to Chrome 152. Users should watch for the next stable channel release in approximately four to six weeks.
