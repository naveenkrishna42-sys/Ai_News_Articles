Android lock screen bug lets Gemini send SMS without PIN

📅 2026-07-19 📂 Technology Original source ↗
Key points
  • Gemini on Android can be used to send SMS without unlocking the phone.
  • The bug bypasses the lock screen's PIN, pattern, or biometric security.
  • Google is aware of the issue and is rolling out a fix.

Gemini bypasses lock screen security

A security vulnerability in Google's Gemini assistant on Android allows anyone with physical access to a locked phone to send text messages. The bug bypasses the usual PIN, pattern, or biometric authentication.

Cybersecurity researchers at Cybernews and Bitdefender reported the flaw. It was also covered by GSMArena.com and Android Headlines. The issue lies in how Gemini handles voice commands when the device is locked.

How the bug works

If a user has Gemini set as the default assistant, an attacker can activate it from the lock screen. By issuing a voice command to send a message, the assistant executes the action without prompting for a password.

The flaw does not require any special tools. Anyone who can press the power button or trigger the wake word can exploit it. This makes it a serious privacy and security risk, especially in public places.

Google responds with a fix

Google has acknowledged the vulnerability and is rolling out a server-side update. The company has not specified when the fix will reach all users. It is likely to be included in a future security patch for Android.

Until the update arrives, users can disable Gemini's lock screen access. This option is available in the app's settings under 'Lock screen' or 'Voice Match'. Turning it off prevents the assistant from responding when the phone is locked.

What users should do now

Android users should check if their device is affected. Go to Settings, then Security & privacy, and review the lock screen preferences for the Google Assistant or Gemini.

Several security firms have published guides on how to mitigate the risk. The simplest step is to revoke Gemini's permission to work when the phone is locked. This does not affect the assistant's functionality when the device is unlocked.

The bug once again highlights the trade-off between convenience and security in modern smartphones. Voice assistants are designed to be helpful, but that help can be exploited if the security boundaries are not properly enforced.

What to watch

Users should watch for Google's official update notification. The company has not yet disclosed whether the fix will be part of the monthly Android security bulletin or a standalone update. Until then, disabling lock screen access for Gemini is the only sure way to prevent unauthorised message sending.
