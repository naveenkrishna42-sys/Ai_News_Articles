The discount is capped at ₹288, which effectively limits the maximum benefit to bookings of ₹5,760 or less. For higher-priced tours—such as multi-day cruises or private guides—the cap means the effective discount rate drops below 5%. The offer is valid through 31 October 2026, giving travellers ample time to plan. Historically, Klook runs similar 5–10% promos during peak travel seasons, but a no-minimum code with a long validity window is relatively rare. At current street prices for Vietnam attractions—ranging from ₹800 for a street food tour to ₹4,500 for a Halong Bay day trip—the code shaves a meaningful amount off mid-range bookings. For a ₹3,000 activity, you save ₹150; for a ₹5,000 booking, you save ₹250. While not a game-changer, it’s a genuine reduction that stacks with existing Klook credits or bank offers in some cases. The code applies only to selected Vietnam experiences, so not every listing on the platform qualifies. Users should verify eligibility at checkout before committing.

Overall, VNATT5AU is a solid, no-fuss option for small to mid-range bookings, but not the absolute best for high-ticket items.

If your total booking is under ₹5,760, you’ll capture the full 5% savings. Budget backpackers will appreciate the no-minimum requirement, as even a ₹1,000 activity gets a ₹50 discount. However, if you’re planning a high-value tour (above ₹6,000), the ₹288 cap means you’re better off looking for a percentage-based code with a higher cap or a flat discount.
