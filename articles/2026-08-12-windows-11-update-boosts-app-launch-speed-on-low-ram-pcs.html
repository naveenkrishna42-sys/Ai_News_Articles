Windows 11 update boosts app launch speed on low-RAM PCs

📅 2026-08-12 📂 Technology Original source ↗
Key points
  • KB5101684 targets low-RAM PCs, improving app launch speed and reliability
  • Update also brings dynamic file sizes in File Explorer and low latency profile for apps
  • Users can enable the feature through Windows Update settings

Microsoft rolls out performance-focused update

Microsoft has begun rolling out Windows 11 update KB5101684, which promises faster app launches on systems with limited RAM. The company says the update makes low-memory PCs more responsive and dependable, addressing a long-standing complaint from users with older hardware.

The update is part of a broader push by Microsoft to optimise Windows 11 for budget and older machines, where memory constraints often lead to sluggish performance. Early reports from Windows Latest and other tech outlets confirm that the patch is now available through Windows Update.

What does KB5101684 include?

Beyond faster app launches, KB5101684 introduces dynamic file sizes in File Explorer. This change lets the file manager display more accurate file size information in real time, reducing the need for manual refreshes and improving overall navigation fluidity.

The update also adds a low latency profile for applications, which prioritises responsiveness for foreground tasks. This is particularly useful for productivity tools and lightweight software that suffer from background processes hogging memory.

Microsoft has not disclosed the exact mechanism behind the performance gains, but insiders suggest the update optimises memory management and prefetching algorithms. For users with 4GB or 8GB RAM, the improvement is reportedly noticeable during app startup and multitasking.

How to enable the update

To get KB5101684, open the Settings app, navigate to Windows Update, and click "Check for updates." The update should appear as an optional or recommended download depending on your system configuration. After installation, a restart is required to apply the changes.

If the update does not show up immediately, users can manually download the .msu file from the Microsoft Update Catalog. Direct download links have been made available by Windows Latest for those who prefer manual installation.

It is worth noting that this update is separate from the Patch Tuesday releases (KB5121003, KB5120240, and KB5121000) that arrived earlier this month. Those updates focused on security fixes and general stability, while KB5101684 is specifically aimed at performance enhancement.

What to expect after installation

Users who have installed the update report faster launch times for common applications like browsers, text editors, and media players. The low latency profile is especially beneficial for real-time collaboration tools that suffer from input lag under memory pressure.

However, some users have noted that the dynamic file sizes feature may cause a slight delay when browsing folders with thousands of files. Microsoft has not yet acknowledged this issue, but it is expected to be addressed in a future cumulative update.

For those running Windows 11 on machines with 16GB or more RAM, the performance gains may be less pronounced. Still, the update is recommended for all users as it also includes under-the-hood reliability fixes.

Looking ahead

Microsoft is expected to continue refining these performance features in upcoming Insider builds. Users who want early access to further optimisations can join the Windows Insider Program, though stability is not guaranteed on pre-release builds.

As more users install KB5101684, the company will likely gather telemetry to fine-tune the memory management changes. If the update proves successful, similar optimisations could be rolled out to Windows 10 in a later servicing release.
