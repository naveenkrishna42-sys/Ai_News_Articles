Microsoft August 2026 Patch Tuesday Fixes 398 Flaws, Active Zero-Day

📅 2026-08-12 📂 Technology Original source ↗
Key points
  • Microsoft patches 398 flaws in August 2026 Patch Tuesday update.
  • One Windows driver zero-day is under active exploitation.
  • Updates include Windows 11 KB5121003, KB5120240, KB5121000 and Windows 10 KB5120249.
  • Total CVEs fixed across products reach 421, per SecurityWeek.

Microsoft has rolled out its August 2026 Patch Tuesday updates, addressing a total of 398 vulnerabilities across its product ecosystem. Among the fixes is a Windows driver zero-day that attackers are already exploiting in the wild, according to The Hacker News.

The update batch includes cumulative updates for Windows 11 and Windows 10, alongside patches for various components. SecurityWeek reports that the full tally of Common Vulnerabilities and Exposures (CVEs) addressed this month reaches 421, suggesting additional fixes beyond the core operating system.

Zero-Day Under Active Attack

The most critical item is the Windows driver flaw, which has been confirmed as actively exploited. Microsoft has not yet disclosed the technical specifics or the extent of the attacks, but the company typically releases such details after a broader rollout.

Security researchers have flagged this as a priority for immediate deployment, given that exploitation is already occurring. Administrators are advised to apply the updates promptly, especially on internet-facing systems.

Update Details for Windows 11 and 10

For Windows 11 users, the updates are available as KB5121003, KB5120240, and KB5121000. These cumulative updates include security improvements and bug fixes, aligning with the standard Patch Tuesday cycle.

Windows 10 users are not left out. Microsoft has released KB5120249 as an extended security update, which is part of its support lifecycle for older operating systems. This update addresses similar vulnerabilities but is tailored for the Windows 10 environment.

Scope of the Patches

The 398 flaws patched this month span a range of severity levels, from critical to moderate. While Microsoft has not categorised each vulnerability in the initial announcement, the company typically provides a detailed breakdown in its security update guide.

The total of 421 CVEs fixed, as noted by SecurityWeek, includes updates for other Microsoft products beyond Windows, such as Office, Edge, and various server components. This reflects the company's ongoing effort to secure its broader ecosystem.

Neowin has also highlighted the availability of these updates, noting that they are part of the regular monthly cycle. Users can download them via Windows Update, Microsoft Update Catalog, or through enterprise management tools.

What Users Should Do

For most users, enabling automatic updates will ensure these patches are installed without manual intervention. However, IT administrators in larger organisations should test the updates in a controlled environment before a full deployment, as is standard practice.

The active zero-day adds urgency to this cycle. Delaying patches could leave systems exposed, particularly if the exploit is being used in targeted attacks.

Microsoft has not yet confirmed whether the zero-day affects all versions of Windows or only specific editions. Further details are expected in the coming days as security firms analyse the updates and the vulnerability itself.

Looking ahead, organisations should monitor Microsoft's security advisories for additional guidance. The company may release out-of-band updates if new information emerges about the zero-day's impact.
