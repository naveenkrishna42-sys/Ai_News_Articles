How to import ChatGPT memories into Claude

📅 2026-08-20 📂 AI Tips & Tools Original source ↗
Key points
  • Claude now supports importing ChatGPT memories
  • Export your ChatGPT data first
  • Use the new import feature in Claude
  • Verify the imported data

How to Import Your ChatGPT Memories into Claude

If you've been using ChatGPT and want to transfer your conversation history to Claude, here's how to do it. This process involves exporting your data from ChatGPT and then importing it into Claude.

Step 1: Export Your ChatGPT Data

  • Log in to your ChatGPT account.
  • Navigate to the settings menu.
  • Look for the 'Export Data' option under the 'Privacy' or 'Account' section.
  • Select the conversations you want to export.
  • Download the exported file to your computer.

Step 2: Prepare the Data for Import

Before importing, ensure your exported data is in a compatible format. Claude accepts JSON files, so if your exported data is in a different format, you may need to convert it.

Step 3: Import Data into Claude

  • Log in to your Claude account.
  • Go to the settings menu.
  • Find the 'Import Data' option under the 'Account' or 'Preferences' section.
  • Upload the JSON file you exported from ChatGPT.
  • Follow the prompts to complete the import process.

Step 4: Verify the Imported Data

After the import is complete, check your conversation history in Claude to ensure all your data has been successfully transferred. Look for the imported conversations in your chat history.

When to Use This Technique

This technique is ideal if you want to continue using Claude but have an extensive conversation history in ChatGPT. It's not suitable if you need to maintain separate accounts or if you prefer not to merge your data. Always ensure you have a backup of your data before performing any import or export operations.
